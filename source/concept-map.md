# 통합컴퓨터시스템 개념 탐색표

독학사 4단계 통합컴퓨터시스템 전 범위(공식 평가영역 15개 대영역 + 교재 200문제 + 모의 2회)를 **인과 순서**로 한 줄로 이은 표야.
앞 번호를 알아야 뒤 번호가 이해되도록 줄 세웠어. 번호대로 내려가면 빠지는 개념이 없어.

## 읽는 법
- **선행** = 이걸 이해하려면 먼저 알아야 하는 노드
- **왜** = 옛날 방식의 문제 → 그래서 이게 나옴
- **핵심** = 시험에 쓸 내용 (공식·정답 포함)
- **계산 이유** = 왜 그렇게 계산할 수밖에 없는지
- **다음** = 이걸 알면 열리는 노드
- **시험** = 1문제 이상 나올 확률(추정) · 유형 · 교재 번호. ⚠️ = 교재 정답표 오류
- **[뿌리]** = 직접 출제는 적어도 뒤 개념 여러 개가 여기서 나옴. 건너뛰지 말 것

## 중요도 5단계
- ★★★★★ 반드시: 확률 50% 이상, 주관식 상위, 공식 예시 출제 주제
- ★★★★☆ 중요: 확률 35~49%
- ★★★☆☆ 보통: 확률 25~34% 또는 뿌리 개념
- ★★☆☆☆ 여유 되면: 확률 15~24%
- ★☆☆☆☆ 눈으로만: 15% 미만 또는 공식 범위 밖

노드 총 147개 · ★5 27개 · ★4 27개 · ★3 48개 · ★2 38개 · ★1 7개

## 제미나이에 붙여넣을 강의 요청문
장 하나(또는 노드 3~6개)씩 아래 요청문 밑에 붙여서 보내. 한 번에 많이 보내면 설명이 얕아져.

```

아래 [노드]들을 번호 순서대로 스토리텔링으로 설명해줘.

규칙
1) 노드마다 '왜' 줄로 시작해: "옛날엔 이런 문제가 있었다 → 그래서 이게 나왔다"
2) '선행' 노드를 한두 줄로 다시 짚고 이어 붙여
3) 자바 비유를 써 (인터럽트 = 이벤트 리스너 콜백, 캐시 = Redis, 스레드풀 = ExecutorService 같은 식)

5) 계산이 있으면 숫자 예시를 한 단계씩 직접 풀어 보여줘
6) 노드 끝마다 "시험엔 이렇게 나온다" 한 줄 + "다음 노드가 이걸 왜 필요로 하는지" 한 줄
7) 폰으로 보니까 문단 짧게

[노드]
(여기에 장 하나 또는 노드 3~6개를 붙여넣기)
```

## 12개 인과 사슬 (장을 가로지르는 연결)
- ① 계산의 뿌리: 트랜지스터 스위치 → 비트 → 부울 대수 → 게이트 → 가산기 → ALU → CPU
- ② 기억의 뿌리: 게이트 + 피드백 → 래치 → (+클록) 플립플롭 → 레지스터·카운터·SRAM
- ③ 2ⁿ의 사슬: n비트 = 2ⁿ가지 → 디코더 n→2ⁿ → MAR n비트 → 주소선 n개 → 캐시·페이지 주소 필드
- ④ 음수의 사슬: 2의 보수 → 뺄셈을 가산기로 → 오버플로 → V 플래그
- ⑤ 속도의 사슬: 명령어 사이클 → 클록·CPI → 성능 계산 → 파이프라인 → 해저드 → RISC
- ⑥ 메모리 속도 차이: 계층 → 지역성 → 캐시 → 사상 → 쓰기 정책 → (멀티코어) 캐시 일관성
- ⑦ 장치 속도 차이: 폴링 → 인터럽트 → DMA → 채널
- ⑧ 실행의 사슬: 소스 → 컴파일 → 어셈블 → 링크 → 로드 → 프로세스 → PCB → 상태 전이 → 스케줄링
- ⑨ 공유의 사슬: 스레드 → 경쟁 조건 → 임계구역 → 세마포어 → (잘못 쓰면) 교착 → 예방·회피·탐지
- ⑩ 공간의 사슬: 분할 → 단편화 → 페이징 → 가상 메모리 → 페이지 부재 → 페이지 교체 → 스래싱
- ⑪ 디스크의 사슬: 탐색시간 → 디스크 스케줄링 / 고장 → RAID / 파일 → 할당 방식 → UNIX i-node
- ⑫ 확장의 사슬: 클록 한계 → 멀티코어 / 특정 목적 → 임베디드 / 자원 낭비 → 가상화 / 공격 → 보안

## 1장. 컴퓨터의 뼈대 (노드 1~2)

> 배선을 바꿔야 프로그램이 바뀌던 시절에서 출발해.

흐름: 프로그램 내장 → 세대 발전 → 트랜지스터 = 스위치 → 비트

**1. 폰노이만 구조·프로그램 내장** ★★★☆☆ [뿌리]
- 선행: 없음 (출발점)
- 왜: 초기 컴퓨터(에니악)는 프로그램을 바꾸려면 전선을 다시 꽂아야 했어
- 핵심: 프로그램도 데이터처럼 메모리에 넣어 두고 CPU가 하나씩 꺼내 실행해. 구성 = CPU(연산·제어) + 메모리 + 입출력 + 이걸 잇는 버스
- 다음: 2 컴퓨터 역사·세대, 34 CPU 구성
- 시험: 25% · 객 · 교재 008

**2. 컴퓨터 역사·세대** ★★☆☆☆
- 선행: 1 폰노이만 구조·프로그램 내장
- 왜: 부품이 작고 빨라질 때마다 세대가 바뀌었어
- 핵심: 1세대 진공관 → 2세대 트랜지스터 → 3세대 IC(집적회로) → 4세대 LSI·VLSI. 에니악(ENIAC) = 10진, 에드박(EDVAC) = 2진·폰노이만 사상. 트랜지스터 = 전기로 켜고 끄는 스위치
- 다음: 3 비트·2진수·자리값
- 시험: 25% · 객 · 교재 008

## 2장. 0과 1로 숫자 표현하기 (노드 3~5)

> 스위치는 켜짐·꺼짐 두 가지만 확실하니까 모든 걸 2진수로 바꿔야 해.

흐름: 비트 → 진법 변환 → 소수의 2진 변환

**3. 비트·2진수·자리값** ★★★☆☆ [뿌리]
- 선행: 2 컴퓨터 역사·세대
- 왜: 스위치(트랜지스터)는 켜짐/꺼짐 2가지만 확실히 구별돼
- 핵심: 비트 = 0/1 한 칸, 바이트 = 8비트. 자리값 …8 4 2 1. n비트 = 2ⁿ가지
- 계산 이유: n비트로 2ⁿ가지 → 나중에 MAR 비트 수, 디코더 출력 수, 주소 필드 계산이 전부 이 한 줄에서 나와
- 다음: 4 진법 변환 (2·8·10·16), 6 부울 대수, 13 디코더·인코더, 18 시프트 연산, 24 클록, 57 캐시 주소 필드, 108 페이징
- 시험: 직접 출제는 드묾 · 모든 계산의 뿌리

**4. 진법 변환 (2·8·10·16)** ★★★★☆
- 선행: 3 비트·2진수·자리값
- 왜: 2진수는 너무 길어서 사람이 읽기 힘들어
- 핵심: 10진 → 2진 = 2로 나눈 나머지를 거꾸로. 2진 → 8진은 3자리씩, 16진은 4자리씩 오른쪽부터 묶기. 8진 ↔ 16진은 2진을 거쳐서
- 계산 이유: 8 = 2³, 16 = 2⁴라서 3자리·4자리로 딱 떨어지게 묶여
- 다음: 5 소수의 2진 변환, 15 음수 표현 3가지·범위, 21 코드 종류 (BCD·3초과·그레이·ASCII·EBCDIC)
- 시험: 45% · 객·주·계산 · 교재 034 040 043 044 050 (⚠️ 040 보기에 정답 없음)

**5. 소수의 2진 변환** ★★☆☆☆
- 선행: 4 진법 변환 (2·8·10·16)
- 왜: 0.5, 0.375 같은 소수도 비트로 나타내야 해
- 핵심: ×2 하고 정수 부분 떼기를 반복. 분모가 2의 거듭제곱이면 끝나고(0.375), 아니면 무한히 반복(0.1) → 잘려서 오차
- 계산 이유: 소수점 아래 자리값이 1/2, 1/4, 1/8이라서
- 다음: 20 부동소수점 (IEEE 754)
- 시험: 부동소수점과 묶여 출제 · 교재 0

## 3장. 계산하는 회로: 게이트와 조합회로 (노드 6~14)

> 스위치를 엮어서 '논리'를 만들고, 논리를 엮어서 덧셈과 선택을 만들어.

흐름: 부울대수 → 게이트 → 법칙·카르노(줄이기) / 마스크 → 조합회로 → 가산기·디코더·MUX

**6. 부울 대수** ★★★☆☆ [뿌리]
- 선행: 3 비트·2진수·자리값
- 왜: 참/거짓을 수식으로 다루면 회로를 식으로 설계할 수 있어
- 핵심: 변수는 0 또는 1. AND = 곱(·), OR = 합(+), NOT = 보수(')
- 다음: 7 기본 게이트·진리표·범용 게이트
- 시험: 게이트·법칙의 뿌리

**7. 기본 게이트·진리표·범용 게이트** ★★★★★
- 선행: 6 부울 대수
- 왜: 부울 연산을 트랜지스터로 만든 부품이 게이트야
- 핵심: 입력 00·01·10·11 순서로 AND 0001 / OR 0111 / NAND 1110 / NOR 1000 / XOR 0110(다르면 1) / XNOR 1001(같으면 1). NAND·NOR 하나만으로 모든 회로를 만들 수 있어서 범용 게이트
- 계산 이유: NAND = AND 결과를 뒤집은 것이라 AND 진리표를 거꾸로 읽으면 끝
- 다음: 8 부울 법칙·드모르간, 10 마스크 연산, 11 조합회로 개념, 21 코드 종류 (BCD·3초과·그레이·ASCII·EBCDIC), 23 패리티·해밍 코드
- 시험: 50% · 객·그림 · 교재 014 032 (⚠️ 014 정답 = XOR)

**8. 부울 법칙·드모르간** ★★★★☆
- 선행: 7 기본 게이트·진리표·범용 게이트
- 왜: 같은 기능을 게이트 적게 만들어야 싸고 빨라 → 식을 줄여야 해
- 핵심: A+0=A, A·1=A, A+1=1, A·0=0, A+A=A, A+A'=1, A·A'=0. 흡수 A+AB=A, A(A+B)=A. A+A'B=A+B. 드모르간 (A+B)'=A'B', (AB)'=A'+B'
- 계산 이유: 흡수법칙: A+AB = A(1+B) = A·1 = A
- 다음: 9 카르노 맵
- 시험: 40% · 객·주 · 교재 027 047 048

**9. 카르노 맵** ★★★☆☆
- 선행: 8 부울 법칙·드모르간
- 왜: 법칙으로 줄이는 건 감이 필요해서 어려워 → 표에 그려서 눈으로 묶자
- 핵심: 1을 1·2·4·8개짜리 직사각형으로 최대한 크게 묶음. 맨 끝과 끝도 이웃. 묶음 안에서 값이 안 변하는 변수만 남김
- 계산 이유: 칸 순서가 00·01·11·10이라 이웃 칸은 변수 1개만 달라 → 그 변수가 A+A'=1로 사라짐
- 다음: — (가지 끝)
